## Canonical Float contract

The runtime reference is one causal endpoint per invocation:

```text
[1,20,80] float32
fresh zero GRU hidden state
three fixed members in seed order 20260828, 20260829, 20260830
member logits and softmax compute float32
member probability promotion to float64
three-member arithmetic mean in float64
inclusive probability >= 0.99
five consecutive 1 ms passes; reset and immediate deassert on failure
```

| Layer | `atol` | `rtol` | Equality requirement |
|---|---:|---:|---|
| preprocessing and model windows | `1e-6` | `1e-6` | shape/dtype exact |
| member logits | `4e-6` | `0` | shape/dtype exact |
| member Hazard probability | `1e-6` | `1e-6` | shape/dtype exact |
| ensemble Hazard probability | `1e-6` | `1e-6` | shape/dtype exact |
| threshold crossing | n/a | n/a | exact |
| consecutive count | n/a | n/a | exact |
| persistence / `REFLEX_REQUIRED` / onset | n/a | n/a | exact |

The preprocessing and probability tolerances are unchanged from M1. Logits use
an absolute-only bound because relative error is ill-conditioned near zero and
faithful Research batch changes already span `2.980232e-6`; `4e-6` is the next
explicit decimal bound above that Research-side envelope. Deployment did not
define or widen these values.

## Threshold sensitivity

The closest canonical golden ensemble value to `0.99` is
`0.9909300009409586`, with absolute margin `0.0009300009409586307`. The nearest
below-threshold margin is `0.0021402939160665158`. At the closest value, combined
ensemble tolerance is `1.9909300009409586e-6`; the observed margin is
`467.118854` times larger. The valid Float paths therefore cannot reach the
threshold within this frozen evidence. Exact discrete parity remains mandatory
independently of that margin.

## Authorization and remaining risks

M3 `INT8_QUANTIZATION_AND_PARITY` is now authorized. M3 inherits the exact
batch-1 Float reference, provenance, ensemble/softmax dtypes, inclusive threshold,
persistence state machine, and exact final decisions. It must define and justify
INT8-specific numerical acceptance and evaluate threshold/onset sensitivity; the
Float tolerance is not an automatic INT8 tolerance.

Remaining risks are:

- numerical characterization covers the frozen non-protected slice, not every
  possible runtime input or future library/backend;
- the `0.99` margin finding is evidence-specific and must be remeasured for INT8;
- E84-specific Vela memory configuration and board timing are not established;
- preprocessing execution cost, invocation overhead, RAM, Flash, firmware, and
  HIL are not measured;
- physical Pelvis IMU integration is outside this project's M5 scope;
- the reference model remains scientifically unsupported for generalization.

No formal quantization, firmware, flash/reset, board execution, or HIL action was
performed in this milestone.
